💧 HydroSafe — AI-Powered Water Quality & Safety Prediction System

HydroSafe is an AI-driven project that predicts the quality and safety level of water using key physicochemical parameters such as pH, turbidity, hardness, solids, and conductivity.
It helps determine whether water is safe, unsafe, or requires treatment, supporting better decisions in environmental monitoring and public health.

🧠 Features

Predicts water safety / quality index from real-world data.
Uses machine learning models (TensorFlow & Scikit-learn) for accurate predictions.
Handles data preprocessing, normalization, and evaluation automatically.
Simple command-line interface for entering test samples.
Modular structure — ready for *web or mobile app integration.
